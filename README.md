## ⚙️ Configuration

All teacher details, contact information, batch dates, fees, and pre-filled WhatsApp messages are centralized in:

```
src/config/teacher.js
```

### To customize:
1. Open `src/config/teacher.js`.
2. Update `whatsappNumber` to your WhatsApp number with country code (e.g., `919876543210`).
3. Add your professional photo to `public/images/naveen.jpg`.
4. Update `batchStartDate`, `batchSchedule`, or `batchFee` as needed.
